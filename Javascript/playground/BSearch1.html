アルゴリズム プレイグラウンド

「実行」を押す（またはEnter）と開始。input()で止まったらターミナル内に入力欄が現れるので、値を打ってEnterで続きが実行されます。

ソースコード

print() / input() は環境が提供する入出力（C++の cout / cin に相当）です。編集して「実行」を押すと、その内容で動きます。
mainは次の3種類のいずれかに対応：function main()（入力なし）／ function* main()（yield* input(msg)で入力待ち）／ async function main()（並列スレッド模擬など、input()を使わないもの）。
main以外の関数（partitionなど）を使うプログラムは、それらもまとめてこの欄に書いてください。
